# Marcela COVID-19 Analysis

This repository contains the cleaned Markdown analysis document and the figure files required for GitHub rendering.

## Contents

- `MarcelaCOVID19analysis.md` — main analysis document
- `figures/` — PNG figures referenced by the analysis document

## Notes

The original repository contained additional unreferenced figures and a project-details file. This cleaned version keeps only the Markdown document and the figure dependencies needed to render it.

The Markdown includes R code examples. One code block contains a hard-coded local path to `JSON_layer.geojson`; that file was not present in the original uploaded repository, and GitHub does not need it to render the document.
